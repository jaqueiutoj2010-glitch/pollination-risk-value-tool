# Note for editors and reviewers

The Pollination Risk and Value Tool V2.41 is a frozen review release accompanying the manuscript.

The **4M analytical dataset** is the reproducible dataset associated with the manuscript calculations. The **expanded Scientific Catalogue** is a complementary evidence-exploration module and is not automatically incorporated into the economic calculations.

The catalogue intentionally preserves differences among evidence types. Qualitative dependence categories, point coefficients, and experimental observations are not treated as interchangeable estimates. The 10%, 25%, and 50% scenarios are standardized stress tests of pollination-service reduction, not climate forecasts or event probabilities.

This review release should remain unchanged during peer review. Scientific catalogue refinements and the definitive article/software citation can be incorporated in a subsequent post-acceptance release.

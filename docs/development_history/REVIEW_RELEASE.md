# Pollination Risk and Value Tool V2.40 — Review Release

Esta versão foi preparada para disponibilização durante a revisão por pares do manuscrito.

## Política da versão
- O conjunto analítico 4M permanece congelado para reprodutibilidade.
- O catálogo científico ampliado é um módulo complementar de consulta e proveniência.
- Nenhum registro do catálogo é transferido automaticamente para os cálculos econômicos.
- Refinamentos taxonômicos e metodológicos não essenciais ao manuscrito ficam reservados para a versão pós-aceitação.
- A citação formal e o DOI do software serão adicionados na versão pública depositada.

## Interface
A interface identifica explicitamente a V2.40 como versão para revisão por pares e explica a separação entre Dados do artigo e Catálogo científico.

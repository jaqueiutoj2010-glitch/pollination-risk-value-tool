# Pollination Risk and Value Tool

Interactive scientific tool for assessing pollination dependency, economic value, and climate-related pollination risk.

## Public Review Release

**Current release: V2.41**

This repository accompanies a manuscript under peer review. The analytical **4M dataset** is frozen for reproducibility. The expanded scientific catalogue is provided for evidence exploration and provenance tracking and is **not automatically incorporated into the economic calculations**.

## Version status

V2.41 is intended for access by editors, reviewers and readers during peer review. Scientific expansion and final catalogue refinements are reserved for a post-acceptance release.
